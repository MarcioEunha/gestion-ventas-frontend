# Gestión de Ventas - Frontend

Aplicación React para la gestión de artículos y ventas.

## Tecnologías
- React
- Vite
- React Router
- CSS

## Funcionalidades
- Crear, leer, actualizar y borrar artículos.
- Buscar artículos por nombre.
- Módulo de ventas con carrito de compras.

## Cómo ejecutar
1. Clonar el repositorio.
2. Instalar dependencias: `npm install`
3. Ejecutar: `npm run dev`
4. Abrir: `http://localhost:5173`

## Backend
Este proyecto se conecta con un backend en Node.js/Express/PostgreSQL. Repositorio: [https://github.com/MarcioEunha/gestion-ventas-backend/tree/main]
